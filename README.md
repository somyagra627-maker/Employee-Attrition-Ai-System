# 💼 Employee Attrition Prediction & Risk Scoring System

## 🚀 Overview
This project uses Machine Learning to predict employee attrition risk and provides explainable HR insights through an interactive dashboard.

---

## 📊 Features
- Employee Attrition Prediction (ML Model)
- Risk Scoring (Low / Medium / High)
- Feature Importance Analysis
- Income, Overtime, Promotion Analysis
- Interactive Streamlit Dashboard
- HR Decision Support System

---

## 🧠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Plotly
